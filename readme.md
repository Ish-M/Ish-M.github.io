# Ishaan Marwaha ePortfolio

Static site (plain HTML/CSS), no build step needed. Edit the .html files directly.

## Publish free on GitHub Pages
1. Create a public repo named `<your-username>.github.io` on GitHub.
2. Upload everything in this folder (keep the folder structure) to the repo root.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / root → Save.
4. In ~1 minute the site is live at `https://<your-username>.github.io`.

## Before submitting
- The Discovery Project Feature is commented out at the top of `projects.html` (search for `DISCOVERY`). Uncomment it and fill it in before the showcase.
- Replace `assets/img/discovery-placeholder.svg` with a real Discovery Project photo.
- Delete the `.todo` / `.todo-block` styles in `assets/css/style.css` once all are gone.
